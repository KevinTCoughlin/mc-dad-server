# Security Policy

## Supported versions

Security fixes land on the current release line, which runs Paper 26.3 on Java 25. Older release lines, including the Java 21 / Minecraft 1.21 release, are not updated.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:

[Open a security advisory](https://github.com/KevinTCoughlin/mc-dad-server/security/advisories/new)

Do not open a public issue for a security report.

Include the version (`mc-dad-server --version`), the operating system, and steps to reproduce. We will acknowledge the report and work on a fix. A public advisory follows once a release is available.
